# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1][covenant] as its
code of conduct. The full text — covering expected behaviour, unacceptable
behaviour, enforcement responsibilities, and the enforcement ladder — lives
at the canonical URL below; we do not maintain a divergent copy.

[covenant]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## Reporting

Conduct concerns can be reported to the maintainers privately at
**conduct@logmind.dev**. Reports are handled in line with the Enforcement
Guidelines section of the Contributor Covenant 2.1.

When the project graduates to a multi-maintainer model the reporting address
will be replaced with a maintainer rota; until then the address forwards to
the project owner.
